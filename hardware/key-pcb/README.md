# Key PCB

Not started. The key's board carries the secure element (a bare Trust M, about 3×3 mm, on a board
6–8 mm wide), a decoupling cap and an optional glow LED, inside the handle of the dual plug. The
pinout, power sequencing and protection rules are in the kickoff:
[Key connector](../../docs/KICKOFF.md#key-connector-draft-pinout) and
[Secure element](../../docs/KICKOFF.md#secure-element).
