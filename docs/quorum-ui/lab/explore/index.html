UI lab

Walk the console's screens

The three-button console, one press at a time. Every picture is a frame the real firmware drew in the emulator, kept when the site was built. Nothing on this page runs the firmware, holds a key or signs. The console page does that.

Flows

    Press the buttons on the picture, or 1, 2 and 3 on a keyboard. Hold D2 to sign. Hold D1 for a second to go back. A press no flow has walked says so: that is a place to add a flow.

    Every screen

    Each screen the flows reach, as first reached. Pick one to go there.

    Built by node tools/uilab/build.mjs from the firmware in the same commit. Something reads wrong, or a press should do something else? Open an issue and paste this page's address: it names the flow and the step.
