# The PicoQuorum name and mark

The licenses in this repository ([MIT](LICENSE) for the code, [CERN-OHL-W-2.0](LICENSE-HARDWARE)
for the hardware, [CC BY-SA 4.0](LICENSE-DOCS) for the docs) cover copyright. They don't cover the
name **PicoQuorum** or its mark (three of five owners joined in a triangle that becomes the Ethereum
diamond: the files in `docs/brand/` and `docs/console/brand/`, what `tools/brand/lockup.py` draws,
and the mark the console draws at boot; [docs/BRAND.md](docs/BRAND.md)).
Those stay with the project, so that a console called PicoQuorum is one people can trust.

**You may, without asking:**
- say that something works with, is built on, or is a fork of PicoQuorum;
- build, run, sell or give away unmodified PicoQuorum firmware, consoles and keys under the name;
- use the mark to link to this project.

**Please ask first before:**
- calling a modified console, key, firmware or app "PicoQuorum", or using the mark on it. A fork
  that changes what gets signed, or how, needs a name of its own, so nobody mistakes it for this
  one. Keep the credit ("based on PicoQuorum") and change the name;
- using the name or the mark in a product name, a company name or a domain.

The firmware's release fingerprint, shown on the console's Device screen, is how anyone tells an
unmodified release from a modified one ([docs/RELEASES.md](docs/RELEASES.md)).

Questions: open an issue, or ask the maintainer, Jason McPheron.
